OUR APPROACH

A forecast you can trace.

01

Freeze the inputs

Player availability and source timestamps are checked before a game starts. Incomplete forecasts are withheld.

02

Simulate the game

Each projection comes from the Monte Carlo play-and-drive engine, with 10,000 simulations per model.

03

Publish the evidence

Every report displays its kickoff and frozen information cutoff so readers know what was available beforehand.
